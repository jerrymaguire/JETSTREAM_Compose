# Web research

1. Turn the request into two or three focused search queries.
2. Use `web_search`; prefer primary sources such as official documentation, standards, release notes, or company pages.
3. Open the strongest results with `web_fetch`.
4. Cross-check important claims with a second independent source.
5. Distinguish facts, source claims, and your own inference.
6. Include the direct source URL beside each important claim.
7. If a page is unavailable or blocked, say so and use an alternative source.
8. Keep raw page text out of the final answer; synthesize it.
