# Task planning

1. Call `update_plan` before starting substantial work.
2. Keep the plan between three and eight steps unless the task is genuinely smaller.
3. Mark exactly one current step `in_progress`; mark completed work `completed`.
4. Update the plan after each meaningful milestone.
5. Do not use the plan as a substitute for doing the work.
6. If blocked, state the blocker and the smallest action needed to continue.
